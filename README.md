## Master Bookmarklet

The **Master Bookmarklet** is a unified interface that provides easy access to all available Suburani bookmarklets in one place. Instead of managing multiple bookmarklets, you can use this single bookmarklet to access all features.

### Features

- **Navigation Tools**: Quickly navigate to chapters, activebooks, translation exercises, and sorting exercises
- **Cheats & Helpers**: Access AI-powered verb trainer and vocabulary helper
- **User-Friendly Interface**: Clean modal UI with organized categories
- **Easy to Use**: Click once to see all options, click again to close

### Installation

1. Open the `Master Bookmarklet.js` file
2. Copy the entire contents (starting with `javascript:(function(){`)
3. Create a new bookmark in your browser
4. Paste the code into the URL/Location field
5. Name it "Suburani Master" or similar
6. Click the bookmark when on any Suburani page to use it

### Available Scripts

#### Navigation
- **Chapter Page**: Navigate to a specific chapter (1-40)
- **Suburani Activebook**: Navigate to Activebook for a chapter (1-40)
- **Autograded Translation**: Navigate to autograded translation exercise (e.g., 7.3)
- **Sorting Exercise**: Navigate to sorting exercise (e.g., 7.3)

#### Cheats & Helpers
- **Verb Trainer AI**: AI-powered Latin verb conjugation helper (requires Gemini API key)
- **Vocab Helper**: Automatic vocabulary answer helper with toggle
